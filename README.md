# 扫雷 Minesweeper

一个基于 Web 的扫雷谜题游戏，原生 SVG 渲染，内置逻辑解题器。

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5210/**。

> 也可以用 `npm run dev`，但不会自动打开浏览器。

## 游戏规则

- 数字表示其周围八格中地雷的数量
- 数字格本身不是雷
- 找出满足所有数字线索的雷布局

## 操作

| 操作 | 说明 |
|------|------|
| 左键点格 | 在雷 / 空之间切换 |
| 右键点格 | 标记 / 取消安全格 |
| 按住拖动 | 连续涂写 |
| 滚轮 / 中键拖拽 | 缩放 / 平移画布 |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / H / S / Esc | 检查 / 提示一格 / 显示解 / 清空 |
| R / L / P / M | 随机抽题 / 逻辑解题 / 暂停回放 / 音效开关 |
| 0 / + / - | 视图复位 / 放大 / 缩小 |

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录；静态部署时自动降级到浏览器 localStorage。

## 功能

- **题库**：内置多道题，题目均校验唯一解
- **实时校验**：冲突与违规位置即时高亮，满足的条件同步变灰
- **逻辑解题**：规则引擎逐帧回放，显示每一步理由；回放中按钮变为停止，按 `P` 暂停/继续
- **提示一格 / 显示解**：提示优先揭示所有解一致的格子，显示解直接填入可行答案
- **撤销/重做**：按手势分组，一次拖拽只需一步撤销
- **进度保存**：自动保存当前题目进度，刷新不丢失
- **音效特效**：Web Audio 合成拨弦、水滴与落子动画，无外部音频资源
- **缩放/平移**：滚轮缩放，中键或 `Shift` 拖拽平移

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage / 项目内 `data/` 存储进度与题库

## 图片识别导入

用 Playwright + Edge 识别题面图片里的网格与数字线索，生成题库格式后预览 / 写入。

```bash
# 只识别 + 预览
npm run import-image -- 题面.png

# 只识别网格与数字
npm run import-image -- 题面.png --dry

# 唯一性检查（大型扫雷题常超时，会给出警告）
npm run import-image -- 题面.png --verify

# 追加到题库（写入 src/game/imported-puzzles.ts，npm run gen 不会覆盖）
npm run import-image -- 题面.png --name "我的扫雷" --append
```

| 参数 | 说明 |
|------|------|
| `--name 名称` | 题库中显示的名称（默认「识图 · W×H」） |
| `--series 系列` | 系列名（默认「图片导入」） |
| `--difficulty 级别` | `easy` / `medium` / `hard` / `custom`（默认 `hard`） |
| `--size N` | 正方形网格边长；默认自动识别 |
| `--width N` / `--height N` | 非正方形题图的宽/高，可只给一边 |
| `--map 行,列=数字` | 人工覆盖某格线索（行列从 1 开始；0-8 为数字，`.` 表示无数字） |
| `--append` | 写入 `src/game/imported-puzzles.ts` |
| `--verify` | 唯一性检查（超时会警告，不阻断导入） |
| `--dry` | 只识别网格与数字，不求解、不写入 |
| `--max-nodes N` | 唯一性搜索节点上限（默认 300000） |
| `--edge PATH` | 指定 Edge 路径（默认自动探测） |

识别流程：以亮度众数作背景色 → 多档阈值投影找网格线 → 每格提取数字墨迹并过滤格子边上的立体高光/阴影 →
多套无衬线字体模板 IoU 匹配 0-9 → 再用「同色必同数字」的多数表决自动纠正个别低置信度字形。
网格外的坐标标签不会被识别成数字。

## 题板尺寸与形状支持

- **题面模型**：`width × height` 数字线索网格（`-1` = 无数字，`0..8` = 九宫格雷数），宽高独立。
- **内置题库**：8×8 正方形。
- **自定义题板**（本次新增，此前完全没有）：宽 4–20、高 4–20，任意非正方形组合；
  点格循环「空 → 0 → 1 → … → 8」，也可键盘 0–8 直填、退格清空；保存/编辑/删除与其它项目一致。
- **识图导入**：自动按网格线识别行列，`--width/--height` 可覆盖；`month.png`（50×50、779 个线索格）识别成功。
- **异形棋盘**：不支持。数字线索依赖每格完整 8 邻域，本项目没有「洞 / 棋盘外空格」概念。
- **验证**：`npm run build`、`npm run check` 通过；内置题参考解与逻辑计划合法；
  自定义题板非正方形（5×6、7×5、9×6、4×4、20×4 / 4×20 极限）编解码、渲染比例、命中、求解闭环实测通过。
- **限制**：20×20 上限是为了让回溯求解/唯一性检查不至于长时间卡住；
  50×50 这类导入大题可以正常加载与游玩，但「求解 / 唯一性」可能超时（有节点上限）。
